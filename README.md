# Air Quality Prediction

A fully Python-based ML web app that predicts **Benzene (C6H6) concentration** (regression) and
**AQI pollution level** (Good / Moderate / Unhealthy / Hazardous — classification) from Italian
metal-oxide chemical sensor data.

| Model | Algorithm | Target | Score |
|---|---|---|---|
| Regression | RandomForestRegressor (200 trees) | C6H6 µg/m³ | **R² = 0.976** |
| Classification | RandomForestClassifier (200 trees) | AQI Level | **Accuracy = 94.6%** |

---

## Project Structure

```
air_quality_project/
├── data/
│   └── Air Quality.csv          # UCI dataset — 9,357 hourly records
├── models/                      # generated by train_model.py
│   ├── model.pkl                # regressor + classifier bundle
│   ├── scaler.pkl               # fitted StandardScaler
│   ├── metadata.json            # feature list, scores
│   └── feature_importances.csv  # regressor feature importances
├── pages/
│   ├── 1_Home.py                # Live single-record prediction + stats
│   ├── 2_Model_Insights.py      # Feature importance, confusion matrix, scatter
│   ├── 3_EDA.py                 # Time-series, distributions, correlations
│   └── 4_Batch_Predict.py       # Upload CSV, download predictions
├── app.py                       # Streamlit entry point (landing page)
├── sidebar_style.py             # Shared CSS, constants, helpers
├── train_model.py               # Training script
├── requirements.txt
└── README.md
```

---

## Setup

```bash
cd air_quality_project
pip install -r requirements.txt
```

## Train the Models

Run once — creates all files in `models/`:

```bash
python train_model.py
```

## Run the App

```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## Column Glossary

| Column | Unit | Description |
|---|---|---|
| CO(GT) | mg/m³ | Carbon Monoxide concentration |
| PT08.S1(CO) | — | Tin oxide CO sensor response |
| C6H6(GT) | µg/m³ | **Benzene — regression target** |
| NOx(GT) | ppb | Nitrogen Oxides |
| NO2(GT) | µg/m³ | Nitrogen Dioxide |
| PT08.S4(NO2) | — | Tungsten oxide NO2 sensor |
| PT08.S5(O3) | — | Indium oxide O3 sensor |
| T | °C | Temperature |
| RH | % | Relative Humidity |
| AH | g/m³ | Absolute Humidity |

## Data Source

UCI ML Repository — [Air Quality Dataset](https://archive.ics.uci.edu/dataset/360/air+quality).
Missing values encoded as **-200** — replaced with column medians during preprocessing.
